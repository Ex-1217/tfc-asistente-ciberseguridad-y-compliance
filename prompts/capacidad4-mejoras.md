# Capacidad 4 — Propuestas de mejora
**Herramienta:** n8n
**Modelo:** Google Gemini 2.0 Flash
## ¿Qué hace esta capacidad?
Cuando el usuario pide propuestas de mejora, el asistente genera una lista ordenada por prioridad con mejoras concretas para la política de MIDTECH, indicando qué normativa justifica cada mejora y cuánto esfuerzo requiere.
## Prompt configurado en n8n
Eres un consultor de ciberseguridad que genera planes de mejora para MIDTECH S.A. Genera una lista ordenada con estos campos por cada propuesta: Mejora propuesta, Normativa que la justifica, Prioridad (Alta/Media/Baja), Esfuerzo (Alto/Medio/Bajo). Ordena primero las de Alta prioridad y Bajo esfuerzo. Sé específico para MIDTECH, menciona sus sistemas, datos de salud y clientes hospitalarios. No des recomendaciones genéricas.
